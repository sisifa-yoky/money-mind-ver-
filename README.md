# MONEY MIND

## ① 課題名

MONEY MIND

## ② 課題内容

MONEY MINDは、日常生活の中でお金と時間をやりくりしながら、7日間を過ごすシミュレーションゲームです。

最初に50,000円と1日8時間の自由時間があり、毎日のタスクをこなしながら、ランダムに発生するイベントに対応していきます。

選んだ行動によってお金や残り時間が変わり、7日間が終わると、最終的に残ったお金に応じてランクが決まります。

## ⑤ 工夫した点・こだわった点

今回、特に挑戦してみたかったのが、プログラミングで数字を計算したり、変化させたりする部分です。

プレイヤーが選んだ内容に合わせて、所持金や時間が自動で増減する仕組みを作りました。

例えば、イベントで選択した後に数字を更新する部分です。

```javascript
button.onclick = () => {
    money += dMoney;
    time += dTime;
    updateDashboard();
};
```

`+=` を使うことで、選択した内容に応じて所持金や時間を増減させています。その後、`updateDashboard()` を呼び出すことで、画面に表示される数字も更新されます。

また、配列を使って毎日のタスクやイベントをまとめることで、それぞれの選択による変化を管理できるようにしました。

## ⑥ 難しかった点・次回トライしたいこと（又は機能）

一番難しかったのは、所持金や時間、現在の日数など、複数の変数を管理することでした。一つの選択によってどの数字がどう変わるのかを考えながら、ゲーム全体が正しく動くようにするのが大変でした。

また、毎日のタスクからランダムイベント、最後の結果発表まで、それぞれの機能をつなげることにも苦労しました。

次回は、選択を確定する前に確認画面を入れてみたいです。一度選んだ内容を確認してから次に進めるようにしたかったのですが、今回は時間が足りず実装できませんでした。
